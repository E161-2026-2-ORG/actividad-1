SYNTAX STYLE

La forma en que el código comunica

Comprender la sintaxis permite escribir instrucciones que las máquinas puedan interpretar. Comprender el estilo permite que esas instrucciones también sean claras para las personas.

¿Qué es Syntax Style?

Dos conceptos distintos, unidos por un mismo objetivo: que el código funcione y se entienda.

Reglas de estilo

Cinco convenciones que transforman código funcional en código legible.

01

Indentación

if (usuario) {
    mostrarPerfil();
}

La indentación facilita identificar visualmente dónde comienza y termina cada bloque de código.

02

Espaciado

let total = precio * cantidad;

let total=precio*cantidad; — sin espacios, más difícil de leer de un vistazo.

03

Nombres descriptivos

let x = 25;
let edadUsuario = 25;

Un nombre descriptivo explica su propósito sin necesitar comentarios adicionales.

04

Consistencia

userName
user_name

Ninguna convención es incorrecta por sí sola; lo importante es mantenerla uniforme en todo el proyecto.

05

Comentarios

// Calcula el total de la compra
const total = precio * cantidad;

Un buen comentario aporta contexto que el código por sí solo no puede transmitir.

Interactividad: ordena el código

total.js 
function calcularTotal(precio,cantidad){
let total=precio*cantidad;
return total;
}
Antes → Menor legibilidad

Cada lenguaje tiene su propia sintaxis

La misma lógica, expresada con reglas distintas.

sumar.js 
function sumar(a, b) {
    return a + b;
}

JavaScript utiliza function, llaves para delimitar bloques y punto y coma opcional al final de cada instrucción.

Diferente sintaxis → mismo objetivo.

◇

Claridad

El código se explica a sí mismo, sin ambigüedad en su intención.

≡

Consistencia

Las mismas reglas se aplican en todo el proyecto, sin excepciones arbitrarias.

◎

Puede modificarse o extenderse con bajo riesgo de introducir errores.

Buenas prácticas

  • Mantener una indentación consistente.
  • Utilizar nombres descriptivos.
  • Mantener un espaciado uniforme.
  • Evitar código innecesariamente complejo.
  • Utilizar comentarios cuando aporten contexto.
  • Seguir las convenciones del lenguaje.
  • Mantener una estructura visual clara.
  • Priorizar la legibilidad.

La sintaxis hace que el código funcione.
El estilo hace que el código se entienda.
